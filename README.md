# Portofolio — Dira Nurbaeti Janah

Portofolio profesional yang menampilkan profil, pengalaman, dan karya Dira Nurbaeti Janah sebagai seorang **Teacher & Educator** yang berdedikasi dalam dunia pendidikan.

## 📋 Tentang Portofolio

Portofolio ini dirancang untuk memperkenalkan latar belakang pendidikan, pengalaman mengajar, keterampilan, dan dokumentasi kegiatan pembelajaran. Website ini menampilkan:

- **Profil Singkat** - Perkenalan dan filosofi mengajar
- **Pendidikan** - Riwayat pendidikan formal
- **Pengalaman Mengajar** - Pengalaman profesional di berbagai institusi pendidikan
- **Keterampilan** - Kompetensi dan pengalaman nyata dalam pengembangan materi pembelajaran
- **Sertifikat & Pelatihan** - Pencapaian dan pengembangan profesional
- **Galeri Dokumentasi** - Dokumentasi visual dari berbagai kegiatan pembelajaran
- **Kontak** - Informasi untuk menghubungi

## 🎯 Fitur Utama

- ✨ **Desain Modern & Responsif** - Tampilan yang menarik dan mudah diakses di berbagai perangkat
- 📱 **Mobile-Friendly** - Optimized untuk smartphone, tablet, dan desktop
- 🖼️ **Galeri Interaktif** - Dokumentasi kegiatan dengan modal popup untuk melihat detail
- 📄 **Download CV** - Fitur download CV langsung dari website
- 🎨 **UI/UX yang Menarik** - Menggunakan warna primary custom (#fa198b) dengan animasi yang halus

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur website
- **CSS3** - Styling dan animasi dengan custom properties
- **JavaScript** - Interaktivitas dan fungsionalitas
- **Bootstrap 5.3.0** - Framework CSS untuk layout responsif
- **Bootstrap Icons** - Icon library untuk UI elements
- **Google Fonts** - Typography (Poppins, Montserrat, Lato, Inter)

## 📁 Struktur File

```
portofolio/
├── index.html          # Halaman utama
├── styles.css          # Stylesheet custom
├── script.js           # JavaScript untuk interaktivitas
├── cv.pdf              # Curriculum Vitae
├── images/             # Folder gambar dan dokumentasi
│   ├── favicon.ico
│   ├── image-1.jpeg
│   └── [gambar dokumentasi lainnya]
└── README.md           # Dokumentasi proyek
```

## 🚀 Cara Menjalankan

1. Clone atau download repository ini
2. Buka file `index.html` di browser
3. Atau gunakan local server (contoh: `python -m http.server 8000`)
